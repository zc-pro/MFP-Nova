# MFP-Nova V6.0 正式架构设计书

V6.0 从氨基酸序列直接产生 Fine39 的 39 个功能分数。研究假设是，同一个短片段在不同肽中可以支持不同功能，周围序列可以帮助判别。每个标签在汇聚前获得自己的窗口分数。同一窗口可以同时支持多个功能。

## 1. 目标与实验依据

主指标是原 Fine39 划分上的样本平均 Jaccard，记为 ACC。强 TheraSet 对照在 8,529 条验证肽上为 **61.2704%**。2,351 条零命中肽中，2,044 条已经报出了至少一个错类标签。即使用真值给定标签数，按原排序截断也只有 66.28%。在原基线和 V5 分路共同漏掉的 333 条肽上，首个已记录标签排名的中位数为 13，首选标签分数中位数为 0.993。V6.0 优先解决功能身份排序，同时保住已判对的标签。70% 是独立 Test 的最终目标。

从 61.2704% 到 70% 需要 **8.73 个百分点**。在同一验证集上，相当于所有肽的 Jaccard 净增约 **744.6**。如果只改历史最难的 333 条，即使全部从零命中变成完全匹配，也只能增加 3.90 个百分点。设计优先覆盖两类错误。第一类是高分错类占据前列，尤其是单标签记录肽。第二类是模型找到第一个功能，但漏掉同一条肽的其他已记录功能。每次比较同时计算找回的收益和损坏原有正确集合的代价。

| 实验 | 对 V6.0 的约束 |
|---|---|
| B0 的 AA34、局部池化、局部 CNN | 验证 ACC 从 50.89% 经 53.47% 到 57.32%。保留逐残基 CNN。 |
| TheraSet 直接头与证据修正 | 历史同 checkpoint 下，直接头 54.27%，融合后 61.05%。修正主要减少额外预测，也压掉了一些正确标签。V6 同时验收召回和多报。 |
| HH 集合编辑、V1.6 联合分布、V2 全肽融合 | 集合编辑没有稳定扩大收益。V2 化学 CNN 为 56.72%，加入全肽 ESM／位置摘要后为 52.47%。首轮直接由窗口证据产生功能分数。 |
| V3 距离带、V4 残基 NLL、V5 分路 | V3 加法与乘法均未超过其 CNN 对照。V4 更低的条件残基 NLL 没转化为更高 ACC。V5 在基线 Top-5 未命中的 963 条肽中，单独上下文路径覆盖 424 条，等权平均覆盖 402 条。将上下文用于解释同一个实际窗口，并让监督直接作用于功能。 |

### 单功能肽方法的取舍

这些方法在各自定义的二分类或活性端点上训练。Fine39 是跨功能的部分标注任务。迁移的依据是方法所暴露的序列线索，以及它是否能在本项目划分下接受相同的验证。

| 原始研究 | 可以借鉴的部分 | 在 V6.0 中的处理 |
|---|---|---|
| AMP Scanner v2、AMPlify | 从一级序列提取局部模式，再利用序列上下文。AMPlify 使用双向 LSTM 和注意力做抗菌预测。 | 复用局部 CNN 和已有逐残基 ESM。把上下文用在具体窗口的功能分数上。AMP 二分类的训练端点无法区分 Gram+、Gram− 或数据库未收录的活性。 [AMP Scanner v2](https://doi.org/10.1093/bioinformatics/bty179) · [AMPlify](https://link.springer.com/article/10.1186/s12864-022-08310-4) |
| Macrel | 小型分类器也能使用有信息的序列描述符。论文单独研究了特征及同源性对性能评估的影响。 | 用便宜的组成和序列探针查证输入信号，模型仍在原划分下验收。范围明确的抗菌二分类特征，作为可用线索进入共享输入。 [Macrel](https://peerj.com/articles/10555/) |
| AntiCP 2.0 | 用抗菌肽作为主数据集的对照，另设以随机肽作为对照的数据集。测试不同背景下的抗癌辨识力。 | 对有抗癌记录且无抗菌记录的肽，专门比较抗菌是否被排在首位。Fine39 中可能共存的功能保持独立输出，未标注位仍用弱权重。 [AntiCP 2.0](https://webs.iiitd.edu.in/raghava/reprints/AntiCP2.pdf) |
| AHTpin、ACE 抑制肽的序列–活性模型 | 肽长、组成和端点位置可提供有用信号。ACE 抑制是明确的测定端点。 | 保留左右距离、左右序列摘要和整肽证据，让各标签自己利用它们。ACE 测定不能用来补齐广义降压标签。 [AHTpin](https://webs.iiitd.edu.in/raghava/reprints/ahtpin.pdf) · [ACE 抑制肽序列–活性研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC11592644/) |
| PreAIP | 用序列、理化、进化和结构特征识别在指定细胞因子测定中有反应的肽，并分析端点特征。 | 把端点作为可观察的序列位置供模型使用。首轮读取既有 ESM 和 AA34，专用结构、进化及测定分支留给有独立证据的问题。 [PreAIP](https://pmc.ncbi.nlm.nih.gov/articles/PMC6411759/) |

做了一个同划分的本地探针来验证端点是否值得独占一条分支。以全肽氨基酸组成和长度为输入，在 Train 拟合同样的岭回归，第二组加入分开的前 3 和后 3 个残基组成。Val 上降压记录 AP 由 **44.19% 增至 45.65%**，抗菌亚类未知由 **43.96% 增至 52.92%**，抗癌亚类未知 AP 由 **15.63% 降至 14.67%**，全 Val 至少命中一个已记录标签的 Top-5 样本比例从 **78.17% 降至 77.75%**。这组结果支持提供端点信息供各功能使用。它没有形成面向全部 39 类的独立端点分类器证据。

AntiCP 2.0 启发的错类对照在本地也有对应样本。用 Fine39 的功能轴归并，在 649 条有抗癌记录、无抗菌记录的验证肽上，TheraSet 的首位标签有 77 条归入抗菌，其中 53 条的已记录抗癌标签仍在 Top-5。首轮比较既看这 53 条的位置是否前移，也看另外 24 条能否产生正确候选。两种恢复分别衡量已有候选的重新排序与此前缺失的候选覆盖。这里的“无抗菌记录”是数据状态。

对宽度 \(k\in\{2,3,4\}\) 枚举 \(w=[a,b)\)，其中 \(b=a+k\le L\)。\(\phi_k\) 拼接按位置排列的 \(k\) 个 AA34 向量，经 \(34k\to128\) 线性投影和 GELU。

\[
\ell_w=\operatorname{LN}\bigl(\phi_k(x_a,\ldots,x_{b-1})\bigr).
\]

该表示在所有窗口间共享参数，首次出现的片段也有完整的输入表示。片段长度的收益先用同一权重下的宽度屏蔽查看。

## 3. 窗口与上下文在打分前交互

~~~mermaid
flowchart LR
    AA["氨基酸骨架"] --> Local["有序 AA34 短窗"]
    AA --> Outside["窗外左右摘要"]
    AA --> CNN["逐残基 CNN"]
    ESM["冻结双 ESM 残基缓存"] --> Align["窗口对齐"]
    CNN --> Align
    Outside --> Context["窗口上下文"]
    Align --> Context
    Local --> Joint["同一窗口内交互"]
    Context --> Joint
    Joint --> Scores["窗口 × 功能分数"]
    CNN --> Global["整肽证据"]
    ESM --> Global
    Scores --> Pool["按功能汇聚"]
    Global --> Pool
    Pool --> Logits["39 个功能 logits"]
~~~

窗口上下文 \(c_w\) 拼接三类对齐信息，经线性投影和 LayerNorm 得到 128 维状态。

- **窗外原始序列。** 分别对 \([0,a)\) 和 \([b,L)\) 的原始 AA34 取均值，并附各侧的有效长度比例。空侧使用零摘要和零长度。使用原始 AA34 前缀和，窗外状态的输入范围可以直接核对。
- **CNN 上下文。** 复用两级 \(3,5,7,9\) 卷积的第二级残基图，沿实际窗口取均值。卷积感受野可以跨出窗口。
- **ESM 上下文。** 两套缓存分别归一化和投影，再取窗口对应的残基 token 均值。ESM token 带有整肽上下文。对齐意味着读取对应位置，窗外原始序列摘要则有严格的输入边界。

令宽度 \(d=128\)、交互秩 \(r=32\)。\(P,Q\) 投影到 \(r\)，\(U\) 投影回 \(d\)。

\[
h_w^{\mathrm{interaction}}
=\operatorname{LN}\bigl(A\ell_w+B c_w+U[(P\ell_w)\odot(Qc_w)]\bigr).
\]

\(U\) 使用无偏置投影并零初始化，从加法通路起步。每个标签用可训练向量 \(q_c\) 得到 \(s_{cw}=q_c^\top h_w/\sqrt d\)。\(q_c\) 以标准正态初始化，与 \(\sqrt d\) 缩放配合。各标签分别评分，允许重叠窗口和多功能共享窗口。

上一稿的线性低秩加法项 \(U(P\ell_w+Qc_w)/\sqrt2\) 可完全并入 \(A\) 与 \(B\)，增加的是线性层的参数化方式。若首轮结果值得确认交互贡献，追加的同参数量对照改用

\[
U\big[(\operatorname{GELU}(P\ell_w)+\operatorname{GELU}(Qc_w))/\sqrt2\big].
\]

该对照具备局部和上下文各自的非线性，保留相同的参数形状、初始加法通路和汇聚。它检验显式跨输入乘积的增量。

V3 在距离带内组合残基对并回写通用残基图。V5 把分路的标签概率等权平均。V6 的可检验贡献是**把局部片段与其位置对齐的上下文在同一窗口内结合，并直接产生功能证据**。PatchCT 提供局部区域与标签对齐的思路，PIAA 支持在全局汇聚前保留局部预测。整肽标注提供弱定位监督，窗口分数的生物学解释要靠独立测定验证。

## 4. 按标签和尺度汇聚

整肽 token \(h_g\) 由有效残基的 CNN 最大池化与双 ESM 均值拼接、投影及 LayerNorm 得到，复用同一个 \(q_c\) 得到 \(s_{cg}=q_c^\top h_g/\sqrt d\)。整肽 token 与窗口状态均为 128 维并经过 LayerNorm，控制两类证据初始的分数尺度。若一个四肽窗口得分为 4、其余均为 0，在所有同宽窗口上作归一化汇聚时，同一峰值在长度 8 的肽上得到 2.46，在长度 74 的肽上只得到 0.56。V6 首轮保留每个标签、每个宽度得分最高的两个有效窗口，再以 \(\tau=1\) 归一化汇聚。

\[
\begin{aligned}
r_{c,k}
&=\tau\left(\log\sum_{w\in\mathcal T_{c,k}}\exp(s_{cw}/\tau)
-\log|\mathcal T_{c,k}|\right),\\
z_c
&=b_c+\tau\left(\log\left[\exp(s_{cg}/\tau)+
\sum_{k\in\{2,3,4\},\,k\le L}\exp(r_{c,k}/\tau)\right]
-\log(1+\#\{k\in\{2,3,4\}:k\le L\})\right).
\end{aligned}
\]

\(\mathcal T_{c,k}\) 取前 \(\min(2,L-k+1)\) 个有效窗口。上述长度 8 和 74 的例子均得 3.33。每种有效宽度在外层占一项，长度 2 时有宽度 2 和整肽两项。内层梯度流向选中的窗口，外层梯度按各宽度和整肽得分分配。重叠窗口允许同时入选。Top-2 能保留峰值，挑选极值带来的长度偏差仍要用分组结果检查。分析时记录各宽度和整肽 token 的权重，判断窗口分支是否实际起作用。偏置 \(b_c\) 用平滑后的 Train 标签频率 logit 初始化，随后学习。最终以独立 sigmoid 输出，保持固定 0.50 阈值。

当 \(L\ge4\)，窗口数为 \(3L-6\)。摘要用前缀和计算，窗口状态按矩阵乘法与全部 39 个标签打分，避免构造窗口、标签和隐藏维度的三轴联合张量。使用 FP32 做有效项的 log-sum-exp。新增窗口计算随长度线性增长。显存和吞吐以完整配置实测。

## 5. 一次主训练与按问题补对照

V6 只对最终 39 个 logit 使用原弱标签 ASL。普通未标注位沿用 0.3 权重，父类已记录、亚类未知时，同轴的未标注位沿用项目降权。antibacterial__unknown 作为 Fine39 中独立的记录标签。Gram+ 和 Gram− 可同时输出。整肽监督从汇聚结果反传到窗口与编码器。首轮使用现有 EMA、普通 Dropout 和 R-Drop 日程，沿用 Fine39 原划分、seed 42、FP32、batch 64、累积 1、固定 0.50 和验证 Jaccard 选模。V6 可训练参数从头初始化，复用两套 ESM 缓存。

| 首轮设置 | 值 |
|---|---|
| 优化器 | AdamW，学习率 0.0002，权重衰减 0.01，梯度裁剪 5 |
| 学习率 | 前 5 轮 warmup，随后沿用训练器的余弦日程 |
| 正则化 | 普通 Dropout 0.2。R-Drop 从第 6 轮起用 5 轮升至 0.1 |
| EMA | 衰减 0.999，沿用训练器的第 6 轮启用日程 |

首轮只完整训练 **V6 交互**，复用原多模态 TheraSet 的 61.2704% 和已保存逐样本预测。该比较回答新模型的整体表现，包含输入范围与读出的差异。沿用最多 100 轮及早停耐心 15。训练前用随机和长肽各一小段真实 batch 检查有 R-Drop 时的显存峰值和吞吐，由此取得 V100 成本。正式训练继续记录训练计算、数据等待与验证时间。历史强基线从第 10 轮起约 **260 秒/轮**，其中验证约 **38 秒/轮**，均为中位数，供实际运行时长比较。V6 复用缓存，主要新增计算是短窗投影和单次窗口到标签的矩阵乘法。

在同一 V6 checkpoint 上，加做两次短前向诊断。第一项把 \(U\) 的输出置零，量化模型对已学交互的依赖。第二项仅在交互项里交换同一肽、同一宽度的窗口上下文，线性通路和整肽 token 照常读取。使用固定的半长循环位移，有效窗口不足两个时跳过交换。该诊断检验窗口对应关系是否影响分数，交换后的特征仅供模型机制分析。

追加训练只回答首轮留下的具体问题。若整体 ACC 提升，且恢复原先排错的功能并保住多功能召回，可用第 3 节的非线性加法组估计显式乘积的增量，并对有效候选做多 seed 验证。若新模型改善正确标签排名，但整体分数仍低，先从同一 checkpoint 检查额外预测、窗口与整肽的权重及各长度分层。输入范围差异确实妨碍判断时，再训练同输入的序列 TheraSet。该组保留旧强架构、双 ESM 和序列 pair。干预测量已训练模型的依赖，重训对照评价换算子的性能差异。若整体和正确标签排序都未改善，先定位输入与取证失效的分组，暂停宽度、交互秩、阈值和正则权重的网格搜索。

## 6. 验收与实现检查

1. **整体。** 报告固定 0.50 的 ACC、Macro-AP、Micro-F1 和按序列簇配对的 ACC 差值区间。
2. **错类。** 报告原基线 2,044 条非空零命中肽中恢复了多少、验证集中新增多少零命中，以及首个已记录标签的排名和功能大类覆盖。
3. **多功能。** 报告两个及三个以上独立功能组的样本 Jaccard、Top-5 正标签位覆盖、阈值下的已记录标签召回和额外未标注位，并报告原有 4,282 条完全匹配的保留率。Top-5 标签位覆盖和至少命中一个标签的样本覆盖分别报告。
4. **泛化与专项。** 在全 Val 上按 Train 近邻相似度分层。历史 333 条难例用于解释错误，选模使用全 Val。Gram 单侧双报与双侧命中保留为诊断。

实现检查集中在长度 2 的有效窗口、随机补齐与上下文掩码、Top-2 从有效位选取、交互前向与反向，以及真实数据短训。运行目录和逐样本导出沿用项目约定。第一轮出现足以推进的收益后再做同协议多 seed 验证，最终用独立 Test 报告 Fine39 样本 Jaccard 是否超过 70%。

## 7. 实现入口

模型名为 `peptide_v6`，默认读取 [首轮配置](../configs/peptide_v6.yaml)，训练任务为 Fine39。默认模式为交互组。`gpu-check` 可在 Fine39 上分别测真实随机和长肽 batch。比较组可通过配置的 `model.mode: additive` 启动独立运行。

对交互组的最佳 checkpoint，`evaluate --split val --v6-diagnostics` 同时计算正常模型、关闭交互与平移上下文的结果，复用每个 batch 的编码。JSON 记录两项干预后的指标和各宽度及整肽的平均权重。指定 `--predictions` 时，NPZ 同时保存按原始行对齐的三组概率、证据权重及其顺序（整肽、宽度 2、3、4）。两项诊断都使用 checkpoint 保存的阈值。
