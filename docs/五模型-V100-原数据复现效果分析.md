# 五模型在 V100 上的原数据复现效果分析

报告日期为 2026-11-03。

## 1. 本轮结论

TPpred-LE、SA-MTP、AMCL、iMFP-LG、METFAN 均已在 V100 上完成一次作者原始主基准的训练及独立测试。结果说明五种方法的训练通路已经可以执行。AMCL 的作者发布权重复测在日志三位小数精度上完全对齐论文表 1；其余模型的论文性能复现程度需要结合各自的配置差异和源码问题判断。

本报告依据用户提供的远端日志、Test CSV 数值，以及本地已核查的作者源码和执行脚本整理。远端 checkpoint、完整预测和结果 JSON 尚未完整传回本机，本次没有重新执行模型推理。各方法均为单次运行，结果未形成多 seed 的均值与标准差。

本轮保持各方法原生输入和训练方法。TPpred-LE、SA-MTP、METFAN 使用 MTP15；AMCL、iMFP-LG 使用 MFTP21。两种基准的标签和样本不同，成绩分别讨论。当前实验尚未涉及 TheraPep49、TheraPep49_positive、TheraPep48 上的重训练，也没有产生 HelixSet 在本轮基准上的对照成绩。

AMCL 的公开默认入口只加载权重预测，本次用本项目脚本接通作者已有训练类。FDL/DBL 权重为0.99/0.01，加0.3倍原对比损失及 flooding；DBL 显式采用 rebalance。沿用公开 FP32 训练循环和无 warm-up、末端学习率为0的余弦调度。论文环境为 Python 3.10、Torch 2.5.1+cu124，并描述使用 AMP，这些差异需要保留。

SA-MTP 与 METFAN 的 ESM2 使用 `facebook/esm2_t33_650M_UR50D`。METFAN 的另一支采用 `Rostlab/prot_t5_xl_half_uniref50-enc`。本项目补充脚本按原 loader 的顺序和过滤条件，使用最后一层残基表征，排除 padding/特殊 token 后做均值池化。提取时加载 FP16，池化累计及保存使用 FP32。ProtT5 使用 `use_fast=False` 解决分词器自动转换失败。

METFAN 论文描述1280维 ESM2、1024维 ProtT5 及均值池化，但在本次所查材料中没有确认其精确 checkpoint 与提取代码。因此本次特征方案应记录为重建设置。使用新名称 `esm2_mean` 后，未显式传特征压缩因子，按源码进入通用默认0.8；`prot_t5_mean` 使用默认0.4。这一点也需要随配置记录，不能假定旧名称 `esm1v_max` 的0.6自动作用于当前 ESM2 特征。

## 4. 各模型复现效果分析

### 4.1 TPpred-LE

发布权重、阶段 A、阶段 B 均完成独立测试。阶段 A 相比发布权重，Jaccard 低1.71个百分点，Micro-F1 低1.50个百分点，完全匹配率低1.46个百分点。单次重训练已经接近这份发布权重，但仍有差距。

阶段 B 相比阶段 A，Micro-Recall 从56.76%升到64.50%，Micro-Precision 从62.42%降到52.82%，Micro-F1 降低1.37个百分点，完全匹配率降低5.96个百分点。该次分类器再训练增加了召回，同时带来更多误报，整体收益有限。阶段 A 与 B 均按既定流程保留，不能依据 Test 挑一个阶段作为后续 seed 的新选模规则。

已确认作者代码通过 `best_model = model` 保存引用，后续优化会继续改变同一对象。阶段 A 的两个内部步骤和阶段 B 都涉及这一行为。因此本轮保存权重不能解释成严格的最低 Val loss 快照。阶段 A、B 的性能差异可能受此影响，但当前实验无法量化其贡献。

**判断**　原始流程已跑通，阶段 A 接近发布权重；修复选模保存后仍需验证训练稳定性。现有三组结果可以作为公开实现的首轮记录。

### 4.2 SA-MTP

三个划分的 ESM2 特征与8190/1023/1024个邻接矩阵均生成成功，所贴完整日志未出现 SS2 缺失回退提示。FiLM warm-up 完成后，下游625.7万参数解冻联合训练，ESM2 保持冻结特征提取。

最低 Val loss 出现在日志 Epoch 13，为0.200873；之后训练损失继续下降，而 Val loss 总体上升，到 Epoch 28 为0.310585并触发早停，表明后期存在过拟合趋势。

该实现也使用可变引用保存“最佳模型”。结合执行顺序，本次最终保存和测试的是第28轮参数状态；阈值随后在这个状态的 Validation 预测上拟合。记录中的最低 Val loss 不是最终 checkpoint 对应的 Val loss。

混合阈值的 Test Micro-F1 为58.90%，Macro-F1 为43.02%，完全匹配率为38.18%。相较 TPpred-LE 阶段 A，Micro-F1 低0.55个百分点，Macro-F1 高0.21个百分点，完全匹配率低4.10个百分点。该单次结果没有表现出一致优势。

逐类方面，AMP F1为75.73%、TXP为68.11%，APP为0，AHTP为20.00%、QSP为18.18%，稀有标签仍较弱。混合阈值相对固定0.5的 Test 平均逐类F1约提升0.97个百分点。MCC优化类别的F1可以下降，不能用这种下降直接认定阈值算法出错。

**判断**　结构特征、模型训练、Val 阈值及独立测试均已执行，但最佳权重保存问题实质影响本轮解释。修复后可复用现有 ESM2 缓存重训。

### 4.3 AMCL

发布权重的五项指标在三位小数精度上完全对齐论文表1。这支持当前数据、过滤、编码、公开权重与原生测试路径能够重现该表格。

补接入口训练200轮后，新权重成功保存并完成阈值优化与 Test。Precision、Recall、Jaccard 各比论文参考值低1.2个百分点，完全匹配率低1.5个百分点，Hamming loss 高0.1个百分点，五项指标与论文报告值接近。

后半程训练损失主要在0.035至0.041附近波动，未见数值发散；本次没有逐轮独立 Val 曲线，不能仅凭 Train loss 判断泛化是否继续改善。原生阈值在增强 Train 上拟合，Test 用于最终打分。

**判断**　发布权重的数值复测已对齐，重建配置下的单次训练接近论文。FP32、环境和补接训练超参数的差异仍应记录，多 seed 稳定性尚未验证。

### 4.4 iMFP-LG

TAPE 初始化文件加载成功，词表大小30、隐藏维度768。编号0完成100轮，最后保存权重并调用 `TestModel(test_iter, ...)`。末尾日志中的“on val”是文字命名问题，五项数值实际来自 Test。

本次 Test Precision 为70.0%、Recall 为71.2%、Jaccard 为65.8%、完全匹配率为57.0%。与 AMCL 重训练相比，Recall 高0.5个百分点，Precision 低5.0个百分点，Jaccard 低3.7个百分点，完全匹配率低6.7个百分点，Hamming loss 高0.5个百分点。由于 Test 覆盖不同，这些是原生协议下的观察差值，不能视为完全相同测试队列的严格差值。

第100轮的 Train Precision 为99.7%，Test Precision 为70.0%，存在明显泛化差距。训练末期 loss约0.349，单看这一数值不能判定训练失败，其含义取决于损失与阈值后的指标。

源码还显示，优化器仅选择参数名包含 `bert` 或 `gat` 的参数，而模型根模块注册的 `FC*` 和 `CLSFC*` 层未进入这两个参数组，因此这些层在本次公开训练流程中不由优化器更新。这是已确认的公开实现细节；当前结果沿用该行为。将这些层纳入优化器属于后续修正实验，需单独说明并重新训练。

**判断**　正确预训练资产、FGM和最终 Test 通路已运行。此次没有做作者任务权重复测，也没有逐项对齐原论文的重复实验统计，当前只能认定一个公开实现成员的训练已完成。

### 4.5 METFAN

本次使用完整的 TextCNN、ESM2、ProtT5 三支特征，并开启特征优化。第189轮达到最佳 Val Macro-F1 0.5640，第239轮因连续50轮无提升而早停。代码在改进时立即保存 state_dict，并在训练末尾恢复已保存权重，最终测试对应第189轮。

Test Jaccard 为59.69%、Macro-F1 为48.60%、完全匹配率为46.73%。相对 TPpred-LE 阶段 A，分别高6.01、5.79、4.44个百分点；Hamming loss 为8.60%，高于阶段 A 的7.61%。这说明当前单次实验的多项集合与类别指标更高，同时按标签计算的错误率也更高，不能由单项成绩推断全面领先。

本地论文全文表1的完整 METFAN 报告 Jaccard 62.3%、Macro-F1 52.2%。本次分别低约2.61和3.60个百分点。该差值仅作参考，本次 checkpoint、特征提取精度和评估协议尚未与作者完整配置逐项对齐。

作者公开评估函数会用传入 Test 的标签寻找逐类阈值。本次补丁把对应阈值保存于最佳 Val checkpoint，并固定用于 Test。因此本次成绩属于重建特征和独立阈值评价设置下的结果，应与公开脚本默认输出分别说明。

**判断**　完整融合模型和独立评价已执行，当前 MTP15 三方法中所提供的 Jaccard、Macro-F1、完全匹配率较高；论文原始数值尚未对齐，仍有明确实现差异。

## 5. 对后续项目推进的判断

本轮已经解决五个方法能否在 V100 上训练和测试的问题，方法覆盖 PSSM/标签嵌入、结构图、增强/对比学习、语言模型微调和多来源特征融合，具备继续研究的基础。

下一步优先修复 TPpred-LE 和 SA-MTP 的最佳轮保存，重新训练受影响部分。SA-MTP 的 ESM2 特征及 SS2、TPpred-LE 的 PSSM 均可复用。iMFP-LG 的优化器参数范围要先明确采用作者原实现还是修正设置，并把两种结果分别命名。AMCL 和 METFAN 在重复实验前固定本轮重建配置，避免逐 seed 根据 Test 调整。

随后补齐必要的连续预测与指标，尤其是 SA-MTP 混合阈值的样本 Jaccard、METFAN 的 Micro-F1，以及 AMCL/iMFP-LG 的 Macro/Micro-F1。指标应从对齐的样本标签和预测重新计算。TPpred-LE 源码把 Micro-AUPR 写死为0，该字段当前表示未计算；其 Macro-AUPR 使用PR曲线梯形面积，与 average precision 的定义也要区分。

在方法设置固定后开展必要多 seed 实验，报告均值和标准差。本轮只有一个 seed，不足以据此确定稳定排名。

迁移到 TheraPep 的工作在原始复现结果厘清后继续。优先从疗效功能预测较直接的 therapep48 入手，再分别训练两个49标签任务。恒正治疗标志和混合任务的全零背景会影响 AMCL 类频率、增强和对比机制，不能只替换文件路径。后续保留各论文自己的处理手段，并按同一 Test 队列汇总。
