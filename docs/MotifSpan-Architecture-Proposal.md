## 1. 核心问题与设计判断

**本轮主设计：**将[总览第8.4节](MFP-Architecture-Design-Study.md#84-最值得主攻的原创候选保留有序交互统计的软片段压缩)的交互保持候选纳入本文：对原始有序关系做软粗化，保留片内关系，用前缀统计避免稠密残基对。图、公式与伪代码统一采用此设计；原片段均值乘积头仅保留为近邻消融。仍未实现、训练。

**同时压缩残基与有序关系，让标签独立读取片段证据、完整关系统计及其空间分布。** 目标是在 TheraPep-AI 的多尺度 CNN 与 HelixSet 的残基对推理之间，构造一个可实现、成本更低、假设更明确的中间方案。

治疗功能可能来自单个局部模式，也可能需要两个区域共同满足条件，例如一个区域提供电荷特征，另一区域提供疏水特征。这里的例子只是建模动机，不能据此断言某个标签一定对应这样的生物学机制。当前五模型已经覆盖模态交互、标签关系、多原型、残基对等路线；继续简单增加一层注意力或一个原型库，难以形成清楚的新问题。

MotifSpan 关注三个可检验假设：

1. 相比全局池化，保留片段位置、宽度与内容有助于区分“相同局部特征出现在不同区域”的序列。
2. 对短肽，少量连续片段之间的显式交互可能已足够；不一定需要维护每一对残基及其三角更新。
3. 同一个片段可以支持多个功能，所以证据读取不应在标签之间实行守恒分配，也不应把未标注标签当成必须匹配的目标。

主方案不使用最优传输求解器，故命名为 **MotifSpan**。OT 是有明确数学定义的对照路线，见第 7 节；“采用最新方法”不能替代判断它的约束是否适合本任务。

### 1.1 唯一实施主配置

| 部分 | 主定义 |
|---|---|
| 输入 | 单650M＋AA34，冻结ESM；150M-F和双路分别比较 |
| 强直接路径 | 两级3/5/7/9 CNN、每核64，融合d256，dropout0.2 |
| 分段 | 有界单调速度，K=min(8,ceil(n/6))，温度0.15/K |
| 单片段证据 | 均值与有界内容池化，独立标签/null读取 |
| 关系原子 | 独立AA34局部编码34→64、核3，有界a/b各32维 |
| 关系压缩 | 固定ρ=0.5/0.9/1，全部K×K软格子，保留片内关系、排除原始i=j |
| 关系读出 | 分段无关的完整统计P＋质量加权、中心化的标签关系读取 |
| 细节回读 | 一层条件/参考残基读取；共享H及K/V，无独立attention dropout |
| 损失 | 现有弱标注ASL，匹配系统的R-Drop/EMA；不默认增加Teacher |
| 输出 | 独立15/39/49维；显式therapep48协议另取48维 |

ηL、ηP、ηR、ηD均从0.1开始且不与读出同时零初始化。原片段乘积头与新关系头互相替换，不同时保留。结构、属性、OT、D/修饰均为独立扩展，不进入纯序列主配置。

### 1.2 改变什么，能够主张什么

旧头只取不同片段的k<l组合，片内关系丢失；软片段重叠时还可能放大同一残基。现在先规定原子关系i<j，再将其分配到全部软格子，序列方向由原子位置决定。K=1仍有片内关系。

主假设是保留关系统计、再读取其分布，有助于紧凑多功能预测。软粗化、乘积和前缀累积均有先例，不声称发明图池化或通用线性注意力。

P对分段A不敏感，所以P本身无法训练边界；标签条件关系读取及单片段路径才训练A。整个预测不要求任意分段下相同，统计保留不等于任意非线性信息无损。

首轮做固定/学习分段×原片段乘积/新关系压缩，统一直接路径、局部关系输入及细节读取。原乘积对照从相同a/b形成片段均值，避免同时改变关系值是否使用ESM；历史PLM片段头另列系统参考。

## 4. 数据语义与输入

覆盖`major15`、`fine39`、`therapep49`三个独立任务。前两者沿用只读迁移包、当前row_id/ID、标签顺序、修复簇划分及原样本；therapep49保留作者CSV成员和49维目标。三个标签空间不合并，也不恢复旧48位编码。

therapep49设计两种Train条件：包含全部发布行，或仅保留`is_therapeutic=True`的真实/恢复正肽。两者保持49维输出，以共同正肽Val前48功能列Micro-F1@0.5选模，在共同Test上分别报告正肽功能与背景诊断；这两条件不是48输出训练；另按therapep48协议时明确改成正肽成员与48维功能目标。队列、行数与作者默认评价的区别见[总览第2.5节](MFP-Architecture-Design-Study.md)。这些选项尚未实现，本轮仅写设计。

该任务只用AA、固定残基理化表和ESM；关闭结构摘要、质心/RBF结构支路、515维性质投影与化学修饰输入。片段压缩、单片段及有序片段对保留，几何补充项为零。这样不会用“正肽有结构、合成背景无结构”的可用性差异泄漏来源。

必须区分三类 mask：

- `PeptideData.indices` 按 `train_original_mask`、`val_original_mask` 等选择**可监督的样本行**；不是一个现成的 `[B,C]`“已知正负标签 mask”。见 [data.py](../src/mfp_nova/data.py)。
- `mask`、`struct_mask`、`phys_mask` 是残基有效性、结构可用性、描述符可用性。它们影响特征运算，不把缺失模态变成负标签。
- `observed_label_loss`有可选逐项mask参数，但不能据此虚构可靠负标签。major15/fine39的0是未标注，fine39的`__unknown`是亚类未知；therapep49的指定背景与全局标志按第6节的任务语义处理。

建议第一版接口直接兼容现有 batch：

| 符号/字段 | 维度 | 使用方式 |
|---|---|---|
| `esm`、可选 `esm_peptide` | `B×L×D650`、`B×L×Dpep` | 冻结缓存，分路无仿射 LN 后拼接投影；不新增预训练。 |
| `aa`、`d`、`residue_chem`、`chemical` | 残基或全局注释 | 保持当前词表与 D/修饰解释；注入 CNN/残基主干。 |
| `mask` | `B×L` | 所有池化、分段、局部卷积输出遵守它。 |
| `phys`、`phys_mask` | `B×515` | 缺失值清零并连接 mask，经小投影得到全局补充特征。 |
| `geometry`、`dssp`、`struct_mask` | `B×L×16`、`B×L` | 片段结构摘要；与纯序列片段保持独立。 |
| `coords`、`confidence_known` | `B×L×3`、`B×L` | 只对有效结构计算片段质心和已知质量。 |
| `y` | `B×C`，`C=15/39/49` | 只用于训练损失；不参与分段、读取及推理。 |

统一五架构归因对照使用共同单650M、共同模态范围；150M-F单路和双路是另外两种直接竞争条件，下文双路公式仅是具体实例。投影输入宽度分别1280/640/1920，其余`d=256`及片段/读出结构不变，单路同样做无仿射LN。150M-F为官方短肽MLM继续预训练权重；已知训练来源并不证明与本项目完全无重叠，650M也不能自动视为无重叠。完整研判与三路实验见[总览第2.4节](MFP-Architecture-Design-Study.md)。前三模型并未自动支持第二缓存。

## 5. 完整架构

~~~mermaid
flowchart LR
    AA[AA34] --> CNN[双级多尺度CNN]
    PLM[冻结ESM] --> H[融合残基H d256]
    CNN --> H
    H --> Z0[强直接预测]
    H --> A[单调软分段A]
    H --> S[均值与内容片段S]
    A --> S
    AA --> L[独立局部编码与a b]
    L --> T[前缀计算全部K乘K关系T和质量m]
    A --> T
    T --> P[完整关系统计P]
    T --> R[中心化标签关系读取]
    S --> R
    S --> E[单片段证据e]
    R --> D[条件与参考残基回读]
    E --> D
    H --> D
    Z0 --> OUT[相加输出]
    P --> OUT
    R --> OUT
    E --> OUT
    D --> OUT
~~~

关系值来自独立局部AA路径，分段和关系选择仍可使用H/S的全局上下文；这不构成严格局域或生物因果模型。第5.3节结构扩展只作用于单片段值，不自动改变本轮关系定义。

### 5.1 保留局部形态，形成残基内容

沿用TheraSet的20 one-hot＋14固定残基属性，先经34→64线性投影，再取两级3/5/7/9 CNN。每尺度为 `Conv→逐位置LN(64)→GELU`，四尺度拼接后dropout0.2；第二级读取第一级256维拼接，得到U。卷积输入（含初始投影后）、每尺度输出及dropout后均在padding位置清零，使用普通零填充。D/修饰扩展只在下式Echem注入，首轮关闭，避免两套化学嵌入。普通线性肽不人为首尾相接。

记注释嵌入为 `Echem`，双缓存投影为 `Eplm`：

\[
H_i=M_i\operatorname{LN}(W_E[\operatorname{LN}(E_i^{650});
\operatorname{LN}(E_i^{pep})]+W_UU_i+E_i^{chem}),\quad H_i\in\mathbb R^{256}.
\]

单缓存消融只删除 `Epep` 项并调整线性层输入，不把零向量伪装成另一个已用编码器。局部 CNN 和固定编码均属于借鉴组件。

这里的“连续片段”约束的是**读取位置**，不是信息的严格局域性。ESM 每个残基已经含全序列上下文，两级 CNN 最大局部感受野也达到17；某个 `S_k` 可能包含其他区间的信息。不能从片段热图推断该功能仅由该段氨基酸决定。默认仍使用完整冻结表征以服务预测；若专门研究局部性，使用已有无ESM成本对照，不把全局缓存上的遮蔽称为重新编码后的序列删除实验。

### 5.2 输入相关的有序连续软分段

对有效长度为 `n` 的每条序列取：

\[
K=\min(8,\max(1,\lceil n/6\rceil)).
\]

这是计算预算规则，不是声称真实基序平均长度为6。默认保持该规则；检验压缩粒度时固定Kmax=8，比较 `K=min(8,max(1,ceil(n/s)))` 的s=4/6/8。仅将Kmax从8提高到12，在当前最大50的Val/Test中只改变n=49/50的K，不能用它检验多数样本的压缩程度。Kmax扩展只有在相关长度段有足够样本时才有意义，不另学离散token数预测器。

用一个小局部卷积从 `H` 得到标量 `b_i`，定义有界正速度与单调坐标：

\[
v_i=1+0.5\tanh(b_i),\qquad
z_i=\frac{\sum_{j\le i}v_j-v_i/2}{\sum_{j=1}^{n}v_j}.
\]

仅对有效位置累计，因此 `z_i` 严格递增，padding 不改变分段。`v_i∈(0.5,1.5)` 限制局部压缩比，避免一个位置占据几乎全部坐标长度。这是连续压缩的具体数值约束，不是额外审批或校验流程。

在变换坐标中设置边界 `t_k=k/K`。令 `F_k(i)=sigmoid((t_k-z_i)/τ)`，`τ=0.15/K`，则：

\[
A_{i1}=F_1(i),\quad A_{ik}=F_k(i)-F_{k-1}(i),\quad
A_{iK}=1-F_{K-1}(i).
\]

`K=1` 时直接 `A_i1=1`。该规则对任意 `n≥1` 都有 `K≤n`，短肽不强行分成 8 份。有效残基满足 `A_ik≥0`、`Σ_k A_ik=1`。每个片段的主体是一段连续区域，边界可软重叠；有限温度下 sigmoid 有尾部，因此不能宣称数学上严格零支持的硬区间。因 `z` 单调，最大隶属片段的次序不会来回跳跃。其边界随输入变化，区别于 GeoFactor 固定宽度划分和无位置自由 latent。

默认n≤6时K=1，没有可学习边界，但T11保留全部有序位点关系；中心化关系摘要为0、完整P仍可用。n=7–12时K=2，有四个软格子，而非四个独立生物相互作用。

分段路径没有 `argmax`、排序、整数边界或 straight-through 估计：`b→v→z→A→S→loss` 全程可微，`∂v/∂b=0.5 sech²(b)`，边界附近 sigmoid 导数非零。速度头末层零初始化使初始 `v=1`，随后可由分类梯度偏离均匀分段；中间隐藏层在首步零初始化投影下暂不更新属于普通初始化现象。`K=1` 时分段头没有梯度是预期结果，因为不存在边界需要学习。实现检查应查看 `K>1` 样本的速度头梯度，不能用只含极短肽的 batch 宣称分段可训练。

记片段质量 `m_k=Σ_i A_ik`、平均相对位置 `μ_k=Σ_i A_ik(i/n)/m_k`、宽度代理 `ℓ_k=m_k/n`。单纯均值可能抹掉短基序，因此增加一个**各标签共享**的有界片段内内容分数 `t_i=2 tanh(w_t^T H_i)`：

\[
\omega_{ik}=\frac{A_{ik}\exp(t_i)}{\sum_jA_{jk}\exp(t_j)},\qquad
S_k=\operatorname{LN}\left(W_S\left[
\frac{\sum_iA_{ik}H_i}{m_k};\ \sum_i\omega_{ik}H_i;
\ \mu_k;\ \ell_k\right]\right)\in\mathbb R^d.
\]

实现时在 log 空间计算 `log A+t` 的片段内 softmax，具体稳定公式如下。有界 `t∈(-2,2)` 把内容放大比限制在 `exp(4)` 以内，避免无界分数轻易覆盖连续隶属度的衰减；它仍是软局部而非严格硬区间。该聚合会同时保留区域平均特征和区域内突出内容；它不是功能位点标注，也不是生物学结构域识别器。

**数值定义进一步落实为稳定的 log 隶属度。** 不先用两个接近1的 sigmoid 相减再取 log。对内部片段设 `a=(t_k−z_i)/τ`、`b=(t_{k−1}−z_i)/τ`，`a>b`，使用完全等价的

\[
\log A_{ik}=\operatorname{logsigmoid}(a)+\operatorname{logsigmoid}(-b)
+\log[-\operatorname{expm1}(b-a)].
\]

首片段为 `logsigmoid((t_1−z)/τ)`，末片段为 `logsigmoid((z−t_{K−1})/τ)`；`K=1` 有效位置取0。均值权重直接用 `softmax_i(log A_ik)`，内容权重用 `softmax_i(log A_ik+t_i)`，`log m_k=logsumexp_i(log A_ik)`。padding/非活动片段为负无穷，并只归约活动片段；避免全负无穷 softmax。分段累计、这些归约及质量计算用FP32。`m_k` 表示分配质量，不能当作真实硬边界长度。

速度头明确为 `DWConv1d(256,256,k=3,padding=1,bias=False)→GELU→Linear(256,1)`；每步屏蔽 padding，最后线性层零初始化。温度固定，不做 annealing；不加熵均衡或边界伪标签。该头只有1,025个参数，先用有界坐标本身约束分段，后续如需更大搜索范围再由固定/学习分段对照决定。

**软重叠的处理。** 单片段S可以重用残基；T只从i<j生成，不包含i=j自项。一条原始关系可分到多个格子，总质量为1。相邻局部CNN窗口仍可能重叠，不宣称关系端点信息独立。不默认加片段排斥损失。

### 5.3 结构作为可衰减补充

定义 `s_i=mask_i ∧ struct_mask_i`。这里 `conf_i=batch["geometry"][...,9]` 已由当前数据装载器除以 100，不能再次除以 100。已知置信度时 `r_i=clip(conf_i,0,1)`，未知置信度时置 `r_i=1`，但显式保留 `confidence_known`；未知置信度不等于高质量已被证实。片段质量系数：

\[
\rho_k=\frac{\sum_i A_{ik}s_ir_i}{m_k}.
\]

将 16 维结构特征、10 维 DSSP one-hot 和 1 维置信度已知标记拼成 `g_i∈R^27`，按已观察质量归一：`G_k=Σ_i A_ik s_i g_i / Σ_i A_ik s_i`。分母为零时返回零值和缺失 mask；覆盖率只通过 `ρ_k` 另行控制，不在 `G_k` 中重复衰减。结构投影先做 LN，再乘 `ρ_k`：

\[
V_k=S_k+\rho_kW_G\operatorname{LN}(G_k).
\]

不能把质量整体缩放后再次 LN，否则衰减可能被归一化抵消。序列分段和 `S` 不依赖结构，缺失结构不会使纯序列通道失效。

结构质心 `c_k=Σ_iA_ik s_i x_i/Σ_iA_ik s_i` 只在有坐标时计算。质心可用于后续独立几何对照，本轮关系主头不读取它。软隶属度有尾部，微量坐标支持可能来自片段主体以外；“分母非零”不能解释为该区间有充分实测覆盖，仍由 `ρ_k` 衰减其贡献。**质心距离不等于残基接触距离**：卷曲片段、缺失片段及长区间都可能失真；如果真实增益需要精细接触，本方案应败给残基对模型，而不靠措辞掩盖这个取舍。

### 5.4 可复用的标签条件单片段证据

每个标签只有一个查询 `q_c∈R^d`，没有多原型银行。标签与片段匹配分数：

\[
s_{ck}=q_c^TW_KS_k/\sqrt d.
\]

每个标签另有空证据分数 `ν_c`，空证据 value 固定为零。采用带基础测度的 softmax：

\[
\alpha_{ck}=\frac{\exp(s_{ck})/K}{\exp(\nu_c)+\sum_j\exp(s_{cj})/K},\qquad
\alpha_{c0}=\frac{\exp(\nu_c)}{\exp(\nu_c)+\sum_j\exp(s_{cj})/K},
\]

\[
e_c=\sum_k\alpha_{ck}W_VV_k,\qquad
\Delta_c^{local}=w_c^Te_c/\sqrt d.
\]

实现为 `softmax(concat(s-log K, ν))`。`1/K` 避免仅因增加等内容 token 就提高相对于空证据的总质量；这个不变性仅针对上述单片段聚合，不扩张到所有不同分段的模型输出。

不同标签的 `α` 独立，不存在 `Σ_c α_ck=1` 的约束。同一片段可同时支持两个已存在的功能；标签也可主要选择空证据。`α` 是内部读权重，不能直接解释成“该片段具有功能 c 的概率”。这种 null-aware attention 本身是已知构造，创新候选在于它和连续分段、片段协同的组合及科研验证。

### 5.5 保留原始有序关系的软压缩

AA34经带bias线性34→64、逐位置LN/GELU、核3的64通道无bias普通卷积、LN/GELU，各步屏蔽padding。a_i=tanh(W_a h_i)、b_i=tanh(W_b h_i)，W_a/W_b为64→32无bias投影、不共享。该局部编码不读取ESM，也不把局部窗口称为已识别基序。

令s=1,2,3对应ρ_s∈{0.5,0.9,1}：

\[
T_{skl}=\sum_{i<j}A_{ik}A_{jl}\rho_s^{j-i-1}(a_i\odot b_j),\quad
m_{skl}=\sum_{i<j}A_{ik}A_{jl}\rho_s^{j-i-1}.
\]

T为B×3×K×K×32，m为B×3×K×K。全部k,l均保留，包括片内k=l和软尾部k>l；真正方向由i<j决定。n<2的关系输出为0，其余路径正常。

\[
P_s=\sum_{kl}T_{skl},\quad Z_s=\sum_{kl}m_{skl},\quad \bar E_s=P_s/Z_s.
\]

由于每个残基Σ_k A_ik=1，P_s等于未分段的完整有序低秩关系和。该性质不保证每条边的身份或任意非线性函数都被保留。

**前缀计算，不构造L×L×r。**

\[
F_{sk}(1)=0,\quad
F_{sk}(j)=\rho_sF_{sk}(j-1)+A_{j-1,k}a_{j-1},
\quad T_{skl}=\sum_j A_{jl}(F_{sk}(j)\odot b_j).
\]

m使用同一递推并令a/b为1。前缀后用einsum缩并，避免普通广播物化B×L×3×K×K×32。首版可构造B×L×3×K×32前缀后缩并，或逐位置累加T；后者不保证更快。A、前缀与关系归约均用FP32。

**完整统计读出：**

\[
\Delta_c^{total}=\sum_s w_{cs}^{\top}\bar E_s/\sqrt r.
\]

**空间关系读出：**

\[
K_{skl}=W_LS_k+W_RS_l+W_T(T_{skl}/Z_s)
+W_\phi[\mu_k,\mu_l,\ell_k,\ell_l]+e_s,
\]
\[
h_{cskl}=4\tanh(u_c^\top K_{skl}/(4\sqrt r)),\quad
w_{skl}=m_{skl}/(3Z_s),\quad
D_c=e^{\xi_c}+\sum_{skl}w_{skl}e^{h_{cskl}}.
\]

W_L/W_R为256→32、W_T为32→32、W_phi为4→32，均无bias；距离编码e_s、标签query u_c为32维。h有界±4，避免任意放大极少质量；4是设计起点而非生物阈值。null分数ξ_c初值0，先验质量Σw=1。

采用中心化关系值：

\[
p_c=D_c^{-1}\sum_{skl}\frac{e^{h_{cskl}}}{3Z_s}
(T_{skl}-m_{skl}\bar E_s),\qquad
\Delta_c^{spatial}=v_c^\top p_c/\sqrt r.
\]

它等价于null注意力读取格子均值相对该距离基完整均值的偏离，但实现不计算T/m，避免除以极小格子质量。取κ_c=max(ξ_c,max有效h)，分子与分母的指数同时减κ。m=0的格子不参与有效最大值；n<2在求Z前分离。关系先验按每个样本自己的有效格子计算，不按batch的Kmax计数。

三条性质：关系值全0时两项均0；每个距离基内h在格子间相同时p=0；K=1时p=0但Δtotal可非零。位置仅影响选择，不通过value直接产生关系分数。这仍不是数据分布上的纯交互分解，也不能排除单点捷径。

不对T或p施加LayerNorm；有界a/b与质量归一控制尺度、保留幅度。正常非零读出及η初始化使关系编码器得到梯度。P不依赖A，边界梯度来自单片段和空间读取，不能只对P做梯度检查。

### 5.6 全局预测与最终输出

`phys` 缺失位置清零后与 `phys_mask` 拼接，经 `1030→64` 线性层及 GELU 得 `gphys`。全局向量为：

\[
g=\operatorname{LN}(W_g[\operatorname{maskedmean}(H);\operatorname{maskedmax}(U);g^{phys}])\in\mathbb R^d,
\]

\[
z_c^{global}=a_c^Tg+b_c,\qquad
z_c=z_c^{global}+\eta_L\Delta_c^{local}
+\eta_P\Delta_c^{total}+\eta_R\Delta_c^{spatial}.
\]

`b_c` 可用 Train 已观察阳性比例初始化；该比例不是已知真实功能发生率。`ηL,ηP,ηR` 为共享可训练标量，初始化为 `0.1`，用于避免随机片段头初始破坏直接路径，不声称它们对应生物学贡献比例。最后各标签独立 `sigmoid(z_c)`，不做标签间 softmax。

保持 `ηL,ηP,ηR` 与片段有符号读出均非零初始化，避免两个串联因子同时为零而阻断学习。首轮记录最终预测相对zglobal的改变量，并分别将local/pair置零做验证诊断；若全局直连已解释全部收益、片段分支长期不改变输出，就不能声称连续压缩有效。分支置零会改变中间分布，仍需重新训练的去分支模型确认归因。

性质扩展的 `gphys` 在投影与GELU后乘 `phys_mask.any`，确保全缺失时为零；核心模式直接不创建该支路。这里已存在全局路径，不能把整网称为所有信息都经过K个片段的严格瓶颈；效率主张只针对显式组合计算从残基级压到片段级。

第一版不增加标签共现图、功能计数头、原型多样性损失、结构重建或 teacher。这些组件若同时加入，会遮蔽“连续片段是否有用”的主要问题。

### 5.7 性能优先扩展：片段组合引导残基细节读取（2026-11-05）

现有核心的主要风险不是pair计算太贵，而是压缩前的信息没有被正确保留。原片段乘积方案约40%的Train只有0或1个片段对；新算子已保留片内统计，但少数关键残基也可能被片段聚合稀释。因此不以进一步减少K作为首要方向。主配置第5.1—5.6节后接如下细节路径：**片段形成组合上下文，再用它从完整残基H读取细节**。进一步修订为同一层中的条件/参考两次读取，不引入迭代循环、额外teacher或新损失。

复用单片段证据 `e_c∈R^256`，并保留片段对向量摘要：

\[
p_c\in\mathbb R^{32}\text{ 由第5.5节中心化关系读取给出},\qquad
\tilde q_c=W_q\operatorname{LN}_0(q_c+e_c)+W_p p_c\in\mathbb R^{128}.
\]

`K=1`时p为零，仍可通过单片段上下文读取残基。LN0无仿射参数；Wq为256→128、Wp为32→128。原有qc继续复用，不另建标签原型库。令：

\[
k_i=W_kH_i,\quad v_i=W_vH_i,\quad
\gamma_{ci}=\operatorname{softmax}_{i\in valid}(\tilde q_c^Tk_i/\sqrt{128}),
\]

\[
t_c(q)=\sum_i\operatorname{softmax}_{i\in valid}(q^Tk_i/\sqrt{128})v_i,\quad
q_c^0=W_q\operatorname{LN}_0(q_c),
\]
\[
z_c^{detail}=z_c+\eta_D w_{D,c}^T[t_c(\tilde q_c)-t_c(q_c^0)]/\sqrt{128}.
\]

Wk、Wv均为256→128，全部新增投影无bias；标签读出wD为C×128，ηD是共享可训练标量、初始化0.1，其余权重正常非零初始化。两次读取共享同一次H、K/V及投影；此小分支不使用两次独立的attention dropout。softmax屏蔽padding，所有输入仅由序列和可用特征产生，不使用真实标签。这里读取完整H，包括原片段权重较低的残基，但不能保证恢复H本身没有的信息。

原先只加t(q条件)存在一个归因漏洞：即便e=p=0，它仍成为普通标签attention分类支路。当前相减使e=p=0时细节增量严格为零，常数value场时也为零；这是模型内部零参考性质，不是“没有真实生物证据”的检测器。参考查询和条件查询都保持梯度，不对参考读取stop-gradient。小型NumPy算例确认零输入增量为0、随机方向有限差分非零；这仅检查代数性质，不能替代未来真实batch的反向测试，也不证明有效片段一定被使用。

新增参数仍为 `3×256×128+32×128+C×128+1`，C=39时**107,393，约0.107M**。K/V投影复用，两组查询各计算一次attention；注意力乘积部分的工作量约为原单读取扩展的两倍，渐近时间仍为 `O(BL·256·128+BC·256·128+BCL·128)`，不构造L×L状态。注意力表为两份B×C×L，吞吐仍需实测。107,393只计细节回读；旧1.33M/1.44M对应旧关系头，不作为新主设计的精确总参数。

本细节路径纳入第1.1节主配置；完整统计、空间关系和单片段路径同时保留。各读取对照使用相同编码器、K及配方。最小比较为：

1. 原有片段核心，无细节读取。
2. 普通标签查询细节读取，查询仅用 `Wq LN0(qc)`；其余读取计算相同，删除不用的Wp，比完整扩展少4,096个参数，不声称严格等参数。
3. 当前中心化片段条件读取，并与不减参考读取的上一轮候选比较；分别移除查询中的e或p并重训，只在完整扩展有收益后检查。若容量差异成为主要解释，再补近似等参数的普通查询投影对照。中心化可能降低最佳性能，届时可选非中心化版本，但不能保留其不具备的零证据性质。

注意力、从粗到细读取以及标签反馈本身都不新；本项目TriRelay已经存在反馈读取。候选贡献仍应表述为**有序连续片段组合是否提供有用的、输入相关的残基读取条件**。需要与普通标签查询读取和现有反馈模型比较；若普通查询同样好，就保留有利于性能的读取而删除它的创新主张。该路线学习TheraPep的局部表示经验，但已经不受其两级CNN加全局池化结构限制。

### 5.8 完整均值与中心化空间读取的边界

P保证所选统计不因分段消失，但对A的导数理论上为0。仅P模型是必要对照，不能证明边界学习有用。空间读取使用关系分布相对完整均值的偏离，负责回答哪些区域比整体平均更有预测价值；因此最终预测可以随分段改变。

中心化不保证更准确。若非中心化质量注意力更强，可以采用它，但不再具有均匀选择时增量为0的性质。新主设计不沿用旧pair输出LN，避免关系幅度被归一化消除。

i<j只排除同一残基显式自乘，局部窗口与全局路由仍可能带入共同信息。若同输入普通有序双线性池化效果相同，就采用简单模型，不把复杂空间读取作为预定结论。

## 6. 损失与训练逻辑

本节z指包含第5.7节细节回读的最终输出；第5.6节z是回读前中间logit。

直接复用 [observed_label_loss](../src/mfp_nova/research_layers.py) 的现有弱未标注 ASL，先隔离架构变化。令 `p=sigmoid(z)`、`q=min(1,1-p+0.03)`，其逐项核心为：

\[
\ell_{bc}=-w_c^+ y_{bc}\log p_{bc}
-w_{bc}^{u}(1-y_{bc})\operatorname{stopgrad}((1-q_{bc})^2)\log q_{bc}.
\]

`w+`来自当前训练队列统计；major15/fine39普通`wu=0.3`，fine39相关具体子类零项再乘0.25。therapep49正肽未标功能仍弱降权；合成背景零项与全局标志零项依现有`unlabeled_weights`权重为1。去掉合成背景的Train条件仍保留正肽未标注项和恒阳性的第49监督，不能把这项实验说成完全没有负向损失。它是训练代理目标，不是严格无偏PU风险。

\[
\mathcal L_{core}=\mathcal L_{obs}(z,y).
\]

默认删除额外 `0.2 Lobs(zglobal,y)`：全局直连已经从最终z的同一分类损失获得梯度，再给它单独监督可能进一步鼓励绕过片段。全局路径保留，用于承载难以压缩的信息；各核心对照均保留相同路径。主配置沿用匹配系统R-Drop/EMA，只有成对机制对照关闭二者；普通网络dropout保留；不加边界监督、均匀覆盖、片段排斥或伪标签损失。

系统主配置明确启用现有R-Drop/EMA。R-Drop按同一输入、同一次模态dropout后的两次网络dropout前向计算，两次分类损失平均；权重0.1，第6epoch开始并渐增，EMA0.999同期启动。若研究全局辅助监督，单独将其系数从0改为0.2，不与片段机制一起变化；它属于训练目标对照，不是默认架构必要组成。

模态dropout仅用于实际有额外模态的训练条件；therapep49关闭它。数据统计、先验和模型参数只用所选Train队列。major15/fine39使用`traditional5/global`；therapep49作者口径用all49 Micro-F1@0.5，有/无背景的受控比较则共同用正肽Val前48功能列Micro-F1@0.5，均固定0.5最终评价。不按Test选择协议或阈值。

主训练预算为最多100 epochs、patience 15，AdamW、初始学习率2e-4、weight decay 0.01、5 epochs warmup后cosine衰减、梯度裁剪5、有效batch 64。物理batch按设备显存选择并用梯度累积补足；沿用总览对应任务的选模指标与阈值规则。以上是待实现起点，并非已验证最优值；同输入架构对照使用相同预算。

## 7. 为什么不把 OT 放进默认模型

把 `K` 个片段直接传输到 `C` 个标签，若规定每个标签接收固定质量，会强迫不存在的标签得到证据；若规定每个片段只能提供总质量 1，又会人为制造多功能标签之间的竞争。非平衡 OT 放松这些约束，并不会自动消除不恰当的边缘先验。

如果后续确实需要“每个标签使用多少片段”的可控先验，可做**每标签独立的二槽半非平衡 OT**对照。对标签 `c`，定义 `T^c∈R_+^(K×2)`，两列为支持/空证据；同一片段在不同标签的 OT 中独立出现，因此可复用。令：

\[
a_k=1/K,\quad C^c_{k,+}=-s_{ck},\quad C^c_{k,0}=-\nu_c,
\]

\[
T_c^*=\arg\min_{T\ge0,\ T\mathbf1_2=a}
\langle T,C^c\rangle+\epsilon\sum_{kj}T_{kj}(\log T_{kj}-1)
+\lambda\operatorname{KL}(T^\top\mathbf1_K\Vert b_c).
\]

其中 `bc=(πc,1-πc)`，`πc` 可以来自停止梯度的全局头概率并做数值裁剪；不得来自真实 Val/Test 标签。把分类概率当作期望支持质量是额外的、未被证明的建模假设，二者没有概率恒等关系，也正是该对照可能失败的原因。用 `T_k,+` 代替单片段读取质量。源边缘严格归一、目标边缘以 KL 惩罚放松，所以准确名称是半非平衡问题，而不是宣称两个边缘都不受约束。

它的代价是熵温度、目标边缘权重和迭代求解，以及全局头错误被传递到局部质量的风险。`λ=0` 时，各行有闭式二分类解 `T_k,+=a_k sigmoid((s_ck-νc)/ε)`，根本不需要 Sinkhorn。只有在非零 `λ` 带来跨 seed 可重复增益，而且不是因额外正则/参数量造成时，才值得保留数值求解。若没有这样的证据，保留第 5.4 节简单读取。

## 8. 最小实现与伪代码

以下是设计规格，不是现有API。使用样本自己的长度、K与mask。

~~~text
U = masked_multiscale_CNN(AA34)
H = masked_fusion(U, selected_frozen_ESM)
z_global = direct_head(masked_mean(H), masked_max(U))
A = monotone_soft_assignment(H, true_lengths)
S = mean_and_bounded_content_pool(H, A)
e, local_delta = independent_label_read_with_null(S)
h_local = masked_local_encoder(AA34)
a, b = tanh(Wa(h_local)), tanh(Wb(h_local))
states = [prefix_and_contract(A, a, b, rho, mask)
          for rho in (0.5, 0.9, 1.0)]
T, mass = stack_on_distance_axis(states)
P, Z = sum_all_span_cells(T, mass)
total_delta = label_linear(P / Z)       # handle n<2 before division
p, spatial_delta = centered_mass_read(S, T, mass, P, Z)
detail_delta = centered_residue_read(H, e, p)
z = z_global + etaL*local_delta + etaP*total_delta
             + etaR*spatial_delta + etaD*detail_delta
loss = existing_observed_label_loss(z, y)
apply_matched_RDrop_and_EMA_schedule()
~~~

局部关系编码器与主CNN是不同模块；图中共享AA不表示共享输出。LN/带bias线性层后、卷积前正确清零padding，残基softmax屏蔽无效位置。只需一个模型文件和配置，复用数据、缓存、损失及训练器。

## 9. 复杂度与资源可行性

| 部分 | 主要算术量，省略batch因子 | 主要中间量 |
|---|---|---|
| ESM融合与CNN | L·D_in·d及局部卷积 | L×d |
| 分段和单片段 | LK d、K d²、CK d | L×K、K×d |
| 关系压缩 | L·3·K²·r，另有局部编码 | 3×K²×r；向量化前缀另有L×3×K×r |
| 中心化关系读取 | 3K²r²、3CK²r及片段投影 | 3×C×K² |
| 细节回读 | Ld·128、Cd·128、CL·128 | 两份C×L注意力，共享K/V |

K最大8；固定K时关系算术量随L线性，K随长度增长的区间不能笼统称全模型严格线性。inactive cells不进入质量和softmax。

K8/r32/三个距离基时T为6144标量/样本，B16/FP32约384KiB；质量约12KiB，C39关系分数约468KiB。B16/L74的前缀约3.47MiB。都不是总训练显存，不含反向保存、CNN、优化器及R-Drop副本。

局部原子编码约18,880参数；关系读取核心约23,911参数（C39，按第5.5节投影与标签向量），η另计。细节回读107,393参数。整网预计仍约1.4–1.6M下游参数，精确值按未来实际共享方式统计一次；不继续引用旧关系头的精确计数。

没有HelixSet的三角传播及稠密pair状态，也没有其全部表达能力。V100/RTX5070均用普通张量算子；短循环可能存在调度成本，数值等价不保证加速。缓存版与含ESM编码的成本分别报告。


## 10. 必要消融、判断依据与失败条件

先使用 seed42、小规模 Train/Val 验证可训练性；有初步证据后再按项目已有固定 seeds `42,101,202,303,404` 做正式比较。不在日常开发默认运行全套模型与全部 seeds。

| 可证伪假设 | 最小对照 | 如果失败，如何收敛设计 |
|---|---|---|
| 学习连续分段优于固定压缩 | 固定 `v_i=1`，其余模块/预算相同 | 若跨 seed 无稳定增益，使用固定分段，删除学习速度头；不再以“自适应基序发现”为贡献。 |
| 连续性而非仅 token 数带来收益 | 相同 K 和近似参数量的无位置约束软 token pooling；取消单调区间归纳偏置 | 若无连续性聚合更好，不能把有序连续片段当作合适的任务假设。 |
| 区域细节有价值 | 片段平均池化 vs 平均+内容池化 | 若差异仅由参数量解释，保留均值及较小投影。 |
| 关系压缩优于压缩后重建关系 | 同局部a/b、同分段与细节读取，比较旧均值乘积和当前关系统计；固定/学习分段各做一次 | 若无增量，不以交互保持解释预测改善；仅保留数学性质的有限结论。 |
| 空间关系读取超出完整统计 | 完整P单独使用、P＋中心化空间R、P＋非中心化读取；全局/单片段/细节路径保持可比 | 若R无增量，采用P；不能用守恒P的收益证明学习分段有价值。 |
| 少量片段足够 | 固定Kmax=8，比较粒度s=4/6/8；必要时同输入残基读出 | 若必须大幅接近残基级才能保持性能，收缩压缩主张；Kmax8→12不作为主要粒度实验。 |
| 允许空证据优于强制读取 | 删除 null、但保持同样分类头 | 若 null 一直被忽略且无性能/校准收益，采用普通读取；不把内部权重解释为机制。 |
| 跨标签复用更符合任务 | 默认独立读取 vs 跨标签归一的对照 | 观察已标注多功能样本，不把预测标签数量当作独立生物学功能数。 |
| 结构摘要提供可靠增量 | `rho=0`、仅序列；按已有质量信息分组查看 Val | 若缺失/低质量结构组明显受损，删除结构摘要，不增加复杂质量网络补救。 |
| OT 的边缘耦合有必要 | 简单读取、`lambda=0` 闭式门、`lambda>0` 半非平衡 OT | 若 OT 无稳定收益或对超参数敏感，默认方案保持无 OT。 |

正式报告同时给出既有传统指标、阈值无关 AP、有效参数量、单步时间/峰值显存和 seed 波动。按长度、结构可用性、Train 独立正簇支持度观察验证集分组表现；稀有组只作描述，不能把少量样本的波动解释成机制证明。只有所有设计和阈值均由 Train/Val 决定后，才按统一方案使用独立 Test。

首轮采用第1.2节固定/学习分段×旧均值乘积/新关系压缩四个条件，同输入与细节读取。若新算子有增量，再比较仅完整P、关闭空间R、非中心化质量读取，以及去掉片内格子的诊断。去片内会改变质量分配：重新归一化与保留原总质量是不同对照，不混用。数学等价的显式边粗化仅核对计算，不重复训练当成另一个模型。

当前Train已支持更具体的可行性判断，统计只用有效原样本，不用Test选择K：

| 默认K对应组 | major15 Train | fine39 Train | 实际可检验机制 |
|---|---:|---:|---|
| K=1，长度≤6 | 3,886 | 3,886 | 无学习边界；P保留片内关系，中心化空间项为0 |
| K=2，长度7–12 | 11,906 | 11,903 | 四个软格子，比较片内统计与空间读取 |
| K=3，长度13–18 | 8,183 | 8,182 | 九个软格子，检验有序统计与空间读取 |
| K≥4，长度≥19 | 15,503 | 15,484 | 多片段组合与连续压缩的主要观察组 |

原方案平均约6个不同片段对、约40%样本只有0或1个pair，仅描述旧头。新模型不丢弃片内关系；K²个格子不是K²个独立关系。逐长度组同时报告类别支持，不把标签组成差异归给压缩。

辅助诊断可报告 `S_k` 在验证集中的质量/边界变化、单片段与pair的有效读取数量 `exp(entropy)` 以及非空证据总质量；它们只说明模块是否被使用。低熵不代表正确基序，高entropy也不意味着失效，不以强制注意力稀疏作为目标。对原序列删改或置换时若仍用原ESM缓存，只能称为特征级干预；真正比较序列扰动需重新提取其ESM，不能把残留全局上下文当成被移除证据。

必要正确性检查限定为：真实 batch forward/backward；padding 变化不改变有效样本输出；`A` 行归一及顺序性；结构缺失时该支路为零；K=1时P可非零、空间项为0，不含原始i=j；弱未标注损失沿用；一次短训练确认没有 NaN/梯度失效。本次未实现网络，因此没有执行上述网络级检查；仅用独立数值例子核对了前缀与显式求和、中心化两种表达、K=1及均匀选择性质，并用有限差分检查了空间读取对分配的敏感性。

## 11. 风险、解释边界与创新主张

**主要风险是压缩丢失信息。** 连续性适合序列邻域，却未必适合空间上相邻、序列上远离的真实作用位点；质心近似也无法恢复被压缩掉的接触。对这种样本，HelixSet/TheraSet 可能更合理。

其次，模型只能在弱标签下学到有预测价值的区间，不能保证这些区间对应真实基序。片段可视化只展示模型取证位置。验证时可对相同长度的连续区域做遮蔽，观察模型输出变化，并与随机区域对照；这种扰动是模型诊断，不是生物活性实验，序列扰动可能离开训练分布。

单调速度范围、最大片段数和温度限制了可表达的边界；这既是正则偏置也是失配来源。如果验证集显示过短关键区间经常被平均掉，应先检查固定/学习分段和内容聚合的对照，而不是立即叠加更多解码器。

可提交为研究贡献的候选是：在弱标注多功能肽预测中，用有序隐式关系粗化保留指定的片内/跨片段统计，再以质量归一和中心化读取区分整体关系与空间差异。软粗化、乘积、前缀求和等各有先例，不预先宣称首次或最优。当前仅完善设计，真实预测收益尚未验证。

组合响应蒸馏只在有效Teacher明确时研究，定义及成本见[总览第8.5节](MFP-Architecture-Design-Study.md#85-可与主线配合的新损失问题压缩后是否保住预测所依赖的组合响应)。不自动叠加Teacher、复杂损失或关联记忆。
